# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 季节温区日历

- 十二个月各存一份清炒温度上下限，默认均为 80–150℃。
- 写入炮制记录必须声明月份，缺月拒写；服务端按当月温区判定放行。
- 改某月温区只向季节流水追加一行，早先流水行不被改写；新温区只约束改线之后提交的记录。
- 质检员（checker）只读各月温区与季节流水，不能写入也不能改线。
- 顶栏挂「季节温区」链接，落地页含十二月温区表、改线区、季节流水。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进「季节温区」：可见十二月温区表、改线区、季节流水三块。
3. 改线区把某月温区抬到 100–150，季节流水追加一行，早先流水不变。
4. 声明该月递交 90℃ 十二分钟 → 未放行；声明另一月（仍 80–150）→ 放行；不声明月份 → 拒写。
5. checker 看不到写入按钮与改线表单，只能查看温区与流水。
